# ベトナムの人口動態 — 最小2ストックモデル (AWAI-2828)

分類: シナリオであって予測ではない。出生・死亡率は GSO 2024中間
国勢調査実測、65歳以上水準は二次集計のため幅あり、純移民は残差、
高齢化係数と高齢死亡倍率は感度仮定。若い東南アジアの対象。

## 実測起点 (GSO)

- 2024年4月1日: 総人口 101.1M、出生率 13.5‰、死亡率 5.6‰、TFR 1.91。
- 65歳以上: 約9.6M (2025年値9.5%相当、二次集計のため幅あり)。
- 純移民 -0.16M/年 (自然増+0.80Mと総増+0.64Mの残差)。

## 構造

```
P' = (b - d) * P + m
E' = a * (P - E) - me * d * E
```

m=-0.16、a=0.006、me=3.0。1年目は総人口と高齢人口の範囲で照合。

## 計算結果 (10年後、2034年)

| シナリオ | 総人口 | 65歳以上 | 高齢化率 |
|---|---|---|---|
| 2024年率固定 | 107.75 | 13.25 | 12.3% |
| 出生1割減 | 106.34 | 13.21 | 12.4% |
| 高齢化加速 | 107.75 | 15.71 | 14.6% |

## 再現

```
grep -e ':birth-rate 0.0135' -e ':death-rate 0.0056' \
     -e ':aging-coef 0.006' -e ':p0 101.1' -e ':e0 9.6' \
     -e ':net-migration -0.16' \
     examples/vietnam-population-aging-scenarios.edn
basilisp run oracle/vietnam_population_oracle_run.cljc \
  > examples/generated/vietnam-population-aging-results.edn
```

basilisp と babashka で小数第3位まで一致を確認。
`.cljc` では loop 変数と係数束縛の同名シャドウを避け、
シナリオ名は定義と照合の全箇所で統一すること (AWAI-2811/2819の教訓)。
