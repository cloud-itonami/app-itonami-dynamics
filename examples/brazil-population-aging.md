# ブラジルの人口・高齢化 — 最小2ストックモデル (AWAI-3359)

分類: シナリオであって予測ではない。起点は Censo Demográfico 2022 の
実測 (2022-08-01 基準、Segunda Apuração)。出生・死亡は 2022 登録実績
(Registro Civil)、純移民は IBGE Projeções Revisão 2024 の STI ベース
 saldo、高齢化係数は 2010→2022 の両国勢調査の実測から中点法で導出、
高齢死亡倍率 3.0 は Tier A/B 共通の仮定。60歳以上 15.6% とは定義が
違う (65歳以上で統一)。

必須シナリオは3本: 基準 (`baseline-2022-rates`) / 純移民ゼロ
(`no-migration`、基準に対し net-migration = 0.0) / 出生率変化
(`lower-fertility`)。`faster-aging` は追加の感度として残し、計4本。

## 実測起点 (Censo 2022 + Registro Civil 2022、同一系列)

- 実測 (人単位、oracle が整数で assert): 総人口 203,080,756。
  0-14歳 40,129,261、15-64歳 140,782,394 (総数−0-14−65+)、
  65歳以上 22,169,101。合計は総人口と完全一致。
- 65歳以上は総人口の 10.916% (公表 10.9%、四捨五入)。
  - 老年従属人口指数 (65+/15-64×100) = 15.747。参考に IBGE の
    高齢化指数 (= 65+/0-14×100) = 55.244、公表の 55.2 と四捨五入で一致。
- 出生 2,542,298 (12.52‰)、死亡 1,504,763 (7.41‰) は発生年 2022。
  2021 の死亡 1,786,347 と比べコロナ減衰後。SINASC 2024 は 2,389,307、
  SIM 2024 は 1,531,936 (Registro Civil 2024 発生 2,376,901 / 1,495,386 と
  ほぼ一致。未登録率は SINASC 0.39%、SIM 1.00%)。
- 純移民 (2022) = −252,799 人/年 (出−131,477、入−121,322)。
  WPP 2023 の −240,059 と同程度。
- 2010→2022 の 65+ 変化 (+8,087,624、年平均 +0.674M) から
  a = (ΔE/年 + m·d·E中) / (P中−E中) = 0.00602。
  これは水準の10年平均であり、直近の速さ (Revisão 2024 調整人口の
  2023→2024: a=0.00744) より保守的。m=3.0 の仮定の影響を含む。

## 構造

```
P' = (b - d) * P + m
E' = a * (P - E) - me * d * E
```

m=-0.252799、a=0.00602、me=3.0。初年は人口 +0.79M (調整人口の
年増 +0.83~0.89M と同程度)、65+ +0.59M/年 (10年平均 +0.67M/年) で
方向・規模は一致。水準は調整人口 (210.86M) と母集団人口 (203.08M) の
差異 (+3.8%) があり、Tier B の方針通り調停していない。

## 計算結果 (10年後、2032年)

| シナリオ | 総人口 | 65歳以上 | 高齢化率 |
|---|---|---|---|
| 2022年率固定 | 211.13 | 27.59 | 13.1% |
| 純移民ゼロ (必須) | 213.72 | 27.66 | 12.9% |
| 出生1割減 | 208.49 | 27.52 | 13.2% |
| 高齢化加速 | 211.13 | 32.30 | 15.3% |

純移民ゼロは基準の net-migration (-0.252799M/年) を 0.0 に置き換え、
出生 (12.52‰)・死亡 (7.41‰)・高齢化係数 (0.00602) は基準と同一。
10年後は基準より総人口 +2.59M (0.2528M/年×10年、複利込み)、
65歳以上ほぼ同等 (27.66 vs 27.59) で高齢化率はむしろ低い (12.9% vs 13.1%)。

出生の差は総人口に 2.6M 効き、高齢化率は出生より係数で決まる。
faster-aging の係数 (0.00903) は直近1年 (0.00744) も超える感度。

## 比較 (Tier B / WPP 2023 との差は調停しない)

- WPP 2023 (Tier B): P 211.14M、65+ 22.45M、CBR 12.32‰、CDR 7.08‰。
  CBR/CDR は実測 (12.52/7.41) と近い。水準の差は推計の構成と年差。
- Revisão 2024 調整人口 (2022-07-01): 210,862,983 (65+ 21,950,033)。
  Censo 2022 との差 (+7.78M) は過少申報調整 (conciliação demográfica,
  Pesquisa de Pós-Enumeração) による。実測起点は国勢調査数。

## 再現

```
grep -e ':birth-rate 0.01251866' -e ':death-rate 0.00740968' \
     -e ':aging-coef 0.00602303' -e ':p0 203.080756' -e ':e0 22.169101' \
     -e ':net-migration -0.252799' \
     examples/brazil-population-aging-scenarios.edn
basilisp run oracle/brazil_population_oracle_run.cljc \
  > examples/generated/brazil-population-aging-results.edn
```

basilisp と babashka で小数第3位まで一致を確認済み (2026-11-24、実測):
Basilisp 0.5.1 と babashka 1.12.218 の両実行で byte-identical
(sha256 `222340d831ae1892b7c37ebf8cfe603f6f4122faa77878acb0f60ca6849ab57b`)。
`.cljc` では loop 変数と係数束縛の同名シャドウを避け、
シナリオ名は定義と照合の全箇所で統一すること (AWAI-2811/2819の教訓)。

  net-migration 0.0 上書きのみであることを検証。

  負テスト: 改ざん係数検出、forged e0 検出、rank/score なし。
