# 沖縄の人口・高齢化 — 最小2ストックモデル (AWAI-2814)

分類: シナリオであって予測ではない。自然・社会増減率と高齢者増加率は
2024年実測。23.8%という高齢者割合の水準は二次引用のため参考扱い。
観光・基地経済は背景として記録し、人数のみ置く。

## 実測起点

- 2024年2月: 総人口 1469.6千人 (県推計)。
- 2024年: 自然増減率 -0.23%、社会増減率 +0.11%、65歳以上人口増加率 +1.6% (全国1位、総務省人口推計)。
- 2025年国勢調査確定値: 1466.548千人。TFR は 2024年1.54・2025年概数1.52で全国1位。

## 構造

```
P' = (n + s) * P
E' = g * E
```

P: 総人口(千人)、E: 65歳以上(千人)。n=-0.0023、s=+0.0011、g=0.016。
1年目は2025年国勢調査 (1466.5±3.0) と高齢推定 (355.4±5.0) で照合。

## 計算結果 (10年後、2034年)

| シナリオ | 総人口 | 65歳以上 | 高齢化率 |
|---|---|---|---|
| 2024年率固定 | 1452.1 | 410.5 | 28.3% |
| 社会増ゼロ | 1436.2 | 410.5 | 28.6% |
| 高齢化半減 | 1452.1 | 378.9 | 26.1% |

社会増ゼロでも高齢人数は変わらず、比率は上がる (分母が縮むため)。

## 再現

```
grep -e ':natural-rate -0.0023' -e ':social-rate 0.0011' \
     -e ':elder-growth 0.016' -e ':p0 1469.6' -e ':e0 349.8' \
     examples/okinawa-population-aging-scenarios.edn
basilisp run oracle/okinawa_population_oracle_run.cljc \
  > examples/generated/okinawa-population-aging-results.edn
```

basilisp と babashka で小数第3位まで一致を確認。
