# シンガポールの人口・超少子化 — 最小2ストックモデル (AWAI-2826)

分類: シナリオであって予測ではない。出生・死亡率は 2024実測、
純移民は残差、高齢化係数と高齢死亡倍率は感度仮定。単位は千人
(他モデルは百万人だが、規模が一桁小さいため)。
都市国家の比較対象。

## 実測起点 (MOH/SingStat/NPTD)

- 2024年: 在住人口 4180.9千人、65歳以上 752.6千人 (18.0%)。
- 2024年: 在住出生 30.808千人、死亡 26.442千人。CBR 7.4‰、CDR 6.0‰。TFR 0.97 (2025年0.87に低下)。
- 純移民 +18千人/年 (在住人口増分との残差)。
- 2025年: 在住人口 4204.5千人。65歳以上割合の母集団定義は表記上曖昧のため、E0 は仮定扱い。

## 構造

```
P' = (b - d) * P + m
E' = a * (P - E) - me * d * E
```

m=18、a=0.010、me=3.0。1年目は2025年推計 (4204.5±5) で照合。

## 計算結果 (10年後、2034年、千人)

| シナリオ | 総人口 | 65歳以上 | 高齢化率 |
|---|---|---|---|
| 2024年率固定 | 4419.8 | 944.4 | 21.4% |
| 出生1割減 | 4387.9 | 943.0 | 21.5% |
| 高齢化加速 | 4419.8 | 1062.6 | 24.0% |

## 再現

```
grep -e ':birth-rate 0.00737' -e ':death-rate 0.006' \
     -e ':aging-coef 0.010' -e ':p0 4180.9' -e ':e0 752.6' \
     -e ':net-migration 18.0' \
     examples/singapore-population-aging-scenarios.edn
basilisp run oracle/singapore_population_oracle_run.cljc \
  > examples/generated/singapore-population-aging-results.edn
```

basilisp と babashka で小数第1位(千人単位)まで一致を確認。
`.cljc` では loop 変数と係数束縛の同名シャドウを避け、
シナリオ名は定義と照合の全箇所で統一すること (AWAI-2811/2819の教訓)。
