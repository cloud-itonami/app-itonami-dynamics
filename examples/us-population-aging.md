# 米国の人口・高齢化 — 最小2ストックモデル (AWAI-2819)

分類: シナリオであって予測ではない。出生率は NCHS 確定値、
死亡総数は二次一致値、純移民と高齢者増加率は Census 実測。
AWAI-2818(日本側)と対になる比較対象。

## 実測起点

- 2024年7月1日: 総人口 340.1M、65歳以上 61.2M (18.0%、前年比+3.1%) (Census Vintage 2024)。
- 2024年: 出生 3.629M (NCHS NVSS確定)、死亡 3.10M (二次一致値)。
- 純移民: 2024年7月までの1年 2.73M、2025年7月までの1年 1.26M (Census)。
- 2025年推計: 341.78M。

## 構造

```
P' = (b - d) * P + m
E' = g * E
```

m=2.73、g=0.031。1年目は2025年推計 (341.78±2.0) で照合。
2025年の移民半減が1年目のズレ要因であり、許容幅に含める。

## 計算結果 (10年後、2034年)

| シナリオ | 総人口 | 65歳以上 | 高齢化率 |
|---|---|---|---|
| 2024年率固定 | 372.9 | 83.4 | 22.4% |
| 移民半減 | 358.1 | 83.4 | 23.3% |
| 高齢化加速 | 372.9 | 91.3 | 24.5% |

移民水準は総人口を動かすが高齢人数はほぼ変わらず、比率は上がる。

## 再現

```
grep -e ':birth-rate 0.01067' -e ':death-rate 0.00912' \
     -e ':elder-growth 0.031' -e ':p0 340.1' -e ':e0 61.2' \
     -e ':net-migration 2.73' \
     examples/us-population-aging-scenarios.edn
basilisp run oracle/us_population_oracle_run.cljc \
  > examples/generated/us-population-aging-results.edn
```

basilisp と babashka で小数第3位まで一致を確認。
`.cljc` では loop 変数と係数束縛の同名シャドウを避け、
シナリオ名は定義と照合の全箇所で統一すること (AWAI-2811/2819の教訓)。
